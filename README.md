# gameso

Три игры для компании прямо в браузере, без сервера: **Глухой телефон**, **Gartic Phone**, **Мемер**.
Мультиплеер на WebRTC (PeerJS): хост — браузер того, кто создал комнату. Остальные подключаются к нему по коду.

## Запуск на GitHub Pages
1. Создай репозиторий `gameso` и залей в корень все файлы (`index.html`, `404.html`, `css/`, `js/`).
2. Settings → Pages → Branch: `main`, папка `/ (root)`.
3. Сайт откроется на `https://1mow.github.io/gameso/`.

Ссылка на комнату вида `https://1mow.github.io/gameso/K7MQ2` работает через `404.html`:
Pages отдаёт её на несуществующий путь, а она перенаправляет на `/gameso/?r=K7MQ2`.
Игрок вводит только ник и сразу попадает в комнату.
Если сайт лежит в корне домена (`user.github.io` или свой домен), поставь `var root = true;` в `404.html`.

Локально: `python3 -m http.server`, комнаты открываются по `http://localhost:8000/?r=КОД`.

## Игры
- **Глухой телефон**: все пишут фразу, листы идут по кругу, каждый пересказывает то, что видит. Можно прятать фразу через 5 или 10 секунд, чтобы писать по памяти. В конце хост листает цепочки.
- **Gartic Phone**: фраза → рисунок → описание → рисунок… Холст с кистью, ластиком, заливкой, 12 цветами, отменой. Первая фраза своя или случайная.
- **Мемер**: у всех одна картинка из Memegen. Пишешь текст сверху (и снизу, если нужно), он ложится шрифтом Impact. Потом мемы показывают по одному, все ставят оценку от 1 до 5, считаются очки.

Реакции 😂🔥💀👏❤️ летят по экрану у всех. Есть звук (кнопка 🔊 сверху) и конфетти на финале.

## Структура
- `js/data.js` — шаблоны мемов, стартовые фразы, аватары, настройки по умолчанию
- `js/net.js` — обёртка над PeerJS (хост, подключение, переподключение)
- `js/host.js` — вся логика игр на стороне хоста
- `js/ui.js` — звук, конфетти, оверлей текста на мемах, холст
- `js/app.js` — экраны и действия игрока
- `css/style.css` — оформление

## Важно знать
- Если хост закрыл вкладку, комната закрывается. Игроки могут переподключиться, пока хост жив.
- Войти в комнату во время игры нельзя, только в лобби. Максимум 12 игроков.
- Публичный брокер PeerJS бесплатный. За строгими NAT (часть мобильных операторов) прямое соединение может не установиться. Тогда нужен TURN-сервер: добавь `config: { iceServers: [...] }` в `new Peer(...)` в `js/net.js`.
- Новые шаблоны мемов: добавь id из https://api.memegen.link/templates в `G.T` в `js/data.js`.
